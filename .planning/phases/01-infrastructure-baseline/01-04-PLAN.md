  <what-built>
Complete Phase 1 infrastructure: pnpm monorepo, Docker Compose (PostgreSQL + Redis), full Prisma schema (all 7 phases), NestJS API with Keycloak JWT auth + RBAC guards, React frontend with keycloak-js SSO login + ProtectedRoute + role-gated pages.
  </what-built>
  <how-to-verify>
**Pre-requisites:** Keycloak server must be running and accessible. Four realm roles must exist in Keycloak: `pm`, `ba`, `developer`, `leadership`. A test user must be assigned at least one of these roles.

**Steps:**

1. **Docker infra:** Run `docker compose up -d` from project root. Verify both services show "healthy" in `docker compose ps`.

2. **Backend:** Run `pnpm dev:api` from project root. Open `http://localhost:3000/api/docs` in browser -- you should see Swagger UI with user endpoints listed.

3. **Frontend:** Run `pnpm dev:web` from project root. Open `http://localhost:5173` in browser.

4. **AUTH-01 (Login):** You should be redirected to the Keycloak login page. Enter your company credentials. After login, you should see the Dashboard page showing your username, email, and roles.

5. **AUTH-02 (Session persistence):** Refresh the browser (F5). You should NOT be redirected to Keycloak login again -- the dashboard should appear immediately.

6. **AUTH-03 (Logout):** Click the "Logout" button on the dashboard. You should be redirected to the Keycloak login page. Navigating back to `http://localhost:5173` should redirect to Keycloak login again (session cleared).

7. **RBAC (role gating):** Log back in with a PM-role user. Navigate to `/pm` -- you should see "PM Dashboard". Navigate to `/ba` -- you should see "Access Denied. Required role: ba" (unless you also have the ba role).

8. **Backend RBAC:** Using a tool like curl or Postman, make a GET request to `http://localhost:3000/api/users/me` with your Bearer token (copy from browser dev tools Network tab). You should get 200 with your user profile. Then try `http://localhost:3000/api/users/pm-only` -- should get 200 if PM role, 403 if not.
  </how-to-verify>
