**Step 1 — Create Prisma schema:**

Run `cd apps/api && npx prisma init` to scaffold `prisma/schema.prisma`.

Then replace the generated schema with the full schema from research (lines 627-853 of 01-RESEARCH.md). The schema contains these models:
- User (id cuid, keycloakId unique, email unique, username, role UserRole enum, timestamps, relations to ownedProjects, projectMembers, assignedTasks, createdTasks, comments, timeLogs, aiJobsRequested)
- Project (id cuid, name, description nullable, archived default false, ownerId FK to User, timestamps, relations to members, sprints, tasks, aiJobs, reports, blueprintSyncs)
- ProjectMember (id cuid, projectId FK, userId FK, role UserRole, joinedAt, @@unique([projectId, userId]))
- Sprint (id cuid, name, projectId FK, startDate, endDate, createdAt, relations to tasks)
- Task (id cuid, title, description nullable, status TaskStatus default BACKLOG, storyPoints nullable Int, acceptanceCriteria nullable, isDraft default false, blueprintId nullable, projectId FK, sprintId nullable FK, assigneeId nullable FK, creatorId FK, timestamps, relations to comments, timeLogs, blueprintSyncs)
- Comment (id cuid, content, taskId FK, authorId FK, parentId nullable self-ref FK for threading, timestamps, parent/replies self-relation "CommentThread")
- TimeLog (id cuid, minutes Int, loggedAt, taskId FK, userId FK, blueprintId nullable)
- AiJob (id cuid, type AiJobType enum, status AiJobStatus enum default PENDING, input Json, output Json nullable, error nullable, bullmqJobId nullable, projectId FK, requestedBy FK, timestamps)
- Report (id cuid, type String 'daily'|'weekly', content String, projectId FK, generatedAt, blueprintId nullable)
- BlueprintSync (id cuid, entityType String, entityId, status SyncStatus enum default PENDING, attempts Int default 0, lastError nullable, projectId FK, taskId nullable FK, syncedAt nullable, timestamps)

Enums: UserRole (pm, ba, developer, leadership), TaskStatus (BACKLOG, IN_PROGRESS, IN_REVIEW, DONE, BLOCKED), AiJobStatus (PENDING, PROCESSING, COMPLETED, FAILED), AiJobType (STORY_GENERATION, TASK_ASSIGNMENT, DAILY_REPORT, WEEKLY_REPORT), SyncStatus (PENDING, SYNCED, FAILED)

Generator uses `prisma-client-js`. Datasource is `postgresql` with `url = env("DATABASE_URL")`.

**Step 2 — Create PrismaService (DI wrapper):**

`apps/api/src/prisma/prisma.service.ts`:
```typescript
import { Injectable, OnModuleInit, OnModuleDestroy } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';

@Injectable()
export class PrismaService extends PrismaClient implements OnModuleInit, OnModuleDestroy {
  async onModuleInit() {
    await this.$connect();
  }
  async onModuleDestroy() {
    await this.$disconnect();
  }
}
```

import { Global, Module } from '@nestjs/common';
