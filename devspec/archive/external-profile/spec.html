external-profile

Self-service profile (name · avatar · password) for EXTERNAL users · status: capturing · depends_on: none
Proposal Architecture Impact Backend Frontend Tasks Coverage

Proposal

Why. EXTERNAL users (PulseTrack email/password, no Keycloak) can't maintain their own profile — name/imageUrl are set at invite and never updated. INTERNAL users re-sync from Keycloak every login (jwt.strategy.ts:75-90), so a local edit is clobbered anyway.

Delivers. A Profile item in the sidebar user footer opening a modal: editable display name, avatar upload (reusing the project-avatar pipeline), and change-password (reusing argon2 helpers). INTERNAL users see it read-only ("Managed by SSO").
