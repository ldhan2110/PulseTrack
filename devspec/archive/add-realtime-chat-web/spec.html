Proposal

Build the web UI users chat in — conversation list, message thread, composer — wired to the add-realtime-chat backend REST + /chat Socket.IO namespace. Integrated into the existing shell (new AppSidebar item + /chat route), not standalone.

Delivers: chat page (Channels + Direct Messages split, thread, composer) · api.ts chat methods + useChat* hooks · /chat socket live updates · unread badge separate from the notification bell · message edit/delete · inline image attachments with copy + paste/drag · infinite-scroll history · text emoji picker (unicode).

Out: all backend (owned by add-realtime-chat) · emoji reactions · chat in the notification bell · search/threads/pinning.

Architecture

ASCII fallback (archify not detected).

AppSidebar  - Chat item + unread badge (useChatUnread) -> route /chat
App.tsx <Route path="/chat"> -> ChatPage
  |- ConversationList  (useConversations) -----------------> api.getChatConversations()
  |    |- Channels group / Direct Messages group
  |    \- search box -> NewConversationDialog (shadcn Dialog)
  |                      (useSearchChatTargets) ------------> api.searchChatTargets(q)
  |                      Message / Open / Join / Create ----> api.createChatConversation()
  \- MessageThread (selected)
       |- useMessages(convId) infinite ---------------------> api.getChatMessages(convId, cursor)
       |- MessageList (grouped; reuse planner ChatMessage)
       |- Composer (reuse planner ChatInput): emoji/image/attach/paste/send
       |    send (useSendMessage optimistic) ---------------> api.sendChatMessage()
       |    upload -----------------------------------------> api.uploadChatAttachment()
       \- edit/delete/markRead -----------------------------> api.*, api.markChatRead()

getChatSocket() ('/chat' ns, Keycloak auth)
  useChatSync(): message:new/updated/deleted, typing, presence, read
       -> qc.setQueryData(['chat', ...])  (live; unread badge recomputed)
