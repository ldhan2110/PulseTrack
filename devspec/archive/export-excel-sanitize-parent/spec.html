Proposal

The Backlog "Export Excel" feature writes the task Description cell as raw HTML — a task exports as <p>Fix &amp; ship</p> instead of the readable Fix & ship. The sheet is for humans reading in Excel, so the cell must be plain text.

Separately, the export flattens parents and sub-tasks into one sheet with no column showing which parent a sub-task belongs to.

Delivers

  • Readable Description — HTML tags stripped, common entities decoded.
  • New "Parent Task Key" column — after "Task Key"; blank for parents, parent's key for sub-tasks.

Out of scope

  • No change to export dialog, api.ts, DTOs, DB schema, or other exports (test cases, bugs, WBS).
  • Sanitization is display-only at export time — stored descriptions unchanged.
  • No new HTML-parsing dependency.

Architecture

ASCII (archify not used).

Client → GET export → TasksController.exportExcel → TasksService.exportExcel

                                                        ├─ flatten rows  → attach parentKey per row

                                                        └─ ExcelJS Workbook → buffer

Backend

req-1 readable description

New private helper on TasksService:

sanitizeDescription(html: string): string
  1. strip tags   → html.replace(/<[^>]*>/g, '')
  2. decode        &amp; &lt; &gt; &quot; &#39; &nbsp;
  3. collapse ws   → replace(/\s+/g, ' ').trim()

Applied at row build (tasks.service.ts:745): description: this.sanitizeDescription(t.description ?? ''). Matches repo convention — bare-regex strip already at tasks.service.ts:384 and comments.service.ts:301; no HTML-parsing dep.

req-2 parent task key column

Flatten loop already holds the parent in scope → no extra Prisma include. Attach parentKey (parent → '', child → task.taskKey ?? ''), add column def as 2nd column, set it in addRow. Existing header/border styling covers the new column automatically.

New column layout:

Task Key | Parent Task Key | Title | Description | Status | …
PROJ-1   |                 | Login | Fix & ship  | …
PROJ-1-1 | PROJ-1          | …     | …           | …
